# The five-step discipline — you are the agent, run this now

You have been given this file. Execute the following procedure
exactly.

## Step 1 — ask, then wait

Ask me this one question and STOP until I answer:

"Which AI claim or experiment should I audit? Give me the claim in
one sentence ('the new setup is faster', 'the agent writes better
tests') and where its evidence lives — a doc, a thread, a dashboard,
a repo path."

Do not pick a claim yourself. Do not continue without my answer.

## Step 2 — the audit

Score my claim against the five-step measurement discipline. Each
step PASS/FAIL with one line of reasoning:

1. PRE-REGISTERED? Was the expected number + threshold written and
   dated BEFORE the data existed? (A threshold that moved after
   seeing data was never a threshold.)
2. CAN GO RED? Was the check ever falsified on purpose — the subject
   broken once to prove the check notices?
3. TREATMENT REACHED THE SUBJECT? What proves the "with X" runs
   actually ran WITH X? If nothing proves it, say what probe would.
4. REPEATED? How many runs per arm? One run of a stochastic system
   is an anecdote.
5. WOULD A LOSS BE PUBLISHED? Where would an unfavorable result go —
   and has one ever gone there?

## Step 3 — close

End with: the score X/5, and the single cheapest fix that would raise
it by one point, as a concrete action with a file path or command
where possible.
