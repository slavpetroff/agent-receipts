# The decision-question test — you are the agent, run this now

You have been given this file inside a repository. Execute the
following procedure exactly.

## Step 1 — build the test

Scan this repo for DECISION-shaped knowledge: places where the team
clearly chose between alternatives (an unusual pattern, a library
where two were possible, a security boundary, something deliberately
NOT done). Write 5 questions about those spots whose answers are
DECISIONS, not facts readable from the code — the shape: not "where
is password hashing" but "where is it ALLOWED to run, and why there?"

For each question also write, separately, what evidence exists in the
repo for the answer (file:line) — or "no recorded evidence" if the
answer lives only in people's heads.

## Step 2 — print the two sheets

Print the 5 questions alone first. Then a cut line. Then the evidence
sheet.

## Step 3 — hand over the clean run

End by printing these instructions, verbatim:

"Now the test itself — I can't run it, because I've just seen the
answers. Open a FRESH session (no history), paste the 5 questions one
by one, and score with the evidence sheet in hand: instant answer
citing your team's real reasoning = correct; searching files for the
question's words and then guessing = wrong, even if close. 0-1
correct: your decisions live in heads and Slack — every session and
every new hire starts from zero. 4-5: your repo carries its own
memory."
